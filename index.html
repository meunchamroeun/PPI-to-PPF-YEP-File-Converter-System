.PPI

Pack Project Installer

Compiled binary file exported by Yamaha Expansion Manager (YEM) for loading directly onto keyboards via USB flash drive. Contains flattened PAC chunks.

Magic: 0x50 41 43 20 ("PAC ")
Target: Flash ROM Direct Ingestion
.PPF

Pack Project File

YEM's editable, unencrypted project container. Formatted as an open ZIP archive containing Pack.xml, User Voice Format (.uvf), and WAV waveforms.

Magic: 0x50 4B 03 04 (PKZip)
Structure: XML Manifest + Assets
.YEP

Yamaha Expansion Pack

Legacy pack format utilized by older generation Yamaha arranger keyboards (PSR-S650, PSR-S750, PSR-S950). Uses structured binary TOC records.

Magic: 0x59 45 50 30 ("YEP0")
Compatibility: Legacy Flash Engine

Node.js Server-Side Worker Logic
worker.js 
import { Worker } from 'bullmq';
import { parsePPIBinary } from './engine/ppi-parser.js';
import { generatePPFArchive } from './engine/ppf-builder.js';
import { db } from './db/postgres.js';

const conversionWorker = new Worker('ppi-conversions', async job => {
  const { fileBuffer, targetFormat, userId } = job.data;
  
  // 1. Parse PPI Chunk Table & Verify DRM
  const packData = parsePPIBinary(fileBuffer);
  if (packData.isProtected) {
    throw new Error('CPI Encryption: Instrument .n27 Key Required');
  }

  // 2. Synthesize output format (PPF Zip or YEP Binary)
  const resultBlob = await generatePPFArchive(packData);
  
  // 3. Save to storage & notify Telegram
  await db.query('UPDATE conversion_jobs SET status = $1 WHERE id = $2', ['COMPLETED', job.id]);
  return { success: true, downloadUrl: `/api/download/${job.id}` };
}, { connection: { host: 'redis', port: 6379 } });
Telegram Bot & Mini App Integration
telegramBot.js 
import { Telegraf } from 'telegraf';

const bot = new Telegraf(process.env.TELEGRAM_BOT_TOKEN);

bot.command('convert', (ctx) => {
  ctx.reply('Open the Yamaha Expansion Converter Mini App below:', {
    reply_markup: {
      inline_keyboard: [[
        { text: 'Launch ExpVoice Studio', web_app: { url: 'https://app.yamaha-converter.io' } }
      ]]
    }
  });
});

bot.on('document', async (ctx) => {
  const doc = ctx.message.document;
  if (doc.file_name.endsWith('.ppi')) {
    ctx.reply(`Received Yamaha pack: ${doc.file_name}. Processing conversion...`);
  }
});

bot.launch();
